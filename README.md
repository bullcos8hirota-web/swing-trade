# スイングトレード支援アプリ

SBI証券で日本株のスイングトレード(数日〜数週間の売買)をするときに、
**買う前の判断材料の整理**と**買ったあとの管理**を助けるためのWebアプリです。

すべてブラウザの中で完結します。サーバーに何も送りませんし、
証券口座に接続することも、発注することもありません。

## できること

| タブ | 内容 |
| --- | --- |
| 監視 | ウォッチリストをスイング目線でスコア化して並べ替え。押し目・ブレイク・トレンドなどの状態が一覧で分かる |
| 銘柄 | ローソク足+移動平均+出来高のチャート、指標のスナップショット、根拠と警戒材料の一覧、売買プラン |
| 建玉 | 保有中のポジションの含み損益、損切り/利確ラインへの到達アラート、トレーリングストップの目安 |
| 記録 | 手仕舞い済みトレードの勝率・期待値・プロフィットファクター・最大ドローダウン、振り返りメモ、CSV書き出し |
| 取込 | 日足CSVの取り込み、当日終値の手入力、SBI証券の取引履歴CSVの取り込み、サンプルデータ |
| 設定 | 運用資金・許容損失・投入上限・利確倍率・手数料・チェックリスト |

### 売買プランの考え方

1. 設定した**運用資金 × 許容損失%**が、1トレードで失ってよい金額になる
2. 損切り価格を決めると「1株あたりのリスク」が決まる
3. 許容損失 ÷ 1株あたりのリスク = **買ってよい株数**(売買単位に丸める)
4. 1銘柄への投入上限を超える場合は、そちらで頭打ちにする

損切り価格の候補は、ATR基準・直近5日安値・25日線の3つから選べます。
価格はすべて東証の呼値(通常銘柄)に丸めます。

## 使い方

```bash
cd swing
npm install
npm run dev      # http://localhost:5173
npm run dev:lan  # スマホから同じLANで開く場合
```

その他のコマンド:

```bash
npm test     # ロジックのテスト(指標・資金計算・CSV解析・シグナル判定)
npm run lint
npm run build
```

初回は「取込」タブの**サンプルデータ**を読み込むと、実在しない銘柄の
架空の値動き5本で一通りの操作を試せます。

## 株価データの入れ方

このアプリは株価を自動取得しません(証券会社の画面をそのまま自動取得すると
規約に触れるため)。次のどれかで入れてください。

- **CSVファイル**: 「日付,始値,高値,安値,終値,出来高」の日足。ヘッダー行があれば列名から自動判別します。Shift_JISのファイルもそのまま読めます
- **貼り付け**: 同じ形式のテキストを貼り付け
- **手入力**: 引け後に当日の1本だけ足す

判定には80本以上(約4か月)を推奨します。同じ日付は後から入れた値で上書きされます。

## SBI証券の取引履歴の取り込み

SBI証券のサイトで「口座管理 > 取引履歴」を開き、CSVをダウンロードして
「取込」タブで読み込むと、買いと売りを古い順(FIFO)に突き合わせて
1トレード単位の記録に変換します。分割売却にも対応しています。
同じ内容を二度読み込んでも重複登録はされません。

## データの保存先

銘柄・株価・トレード記録はすべてブラウザのIndexedDBに保存されます。
設定画面から全削除できます。別の端末とは共有されません。

## 注意

- 将来の値動きを予測するものではなく、特定の銘柄の売買を推奨するものでもありません。投資判断はご自身の責任で行ってください
- SBI証券とは無関係の個人ツールです。発注機能はありません
- 手数料は初期値を0円(ゼロ革命想定)にしています。プランや条件によって異なるので、設定画面で最新の料金体系に合わせてください
- 呼値は通常銘柄の刻みを目安として使っています(TOPIX500採用銘柄はより細かい刻みです)
